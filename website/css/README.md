# website/css/

## What is this folder?

All the **styles** for Study Buddy live here.
We split CSS into three files so each file has one job (easier to learn and find things).

## What files matter?

| File | Job |
|------|-----|
| `base.css` | Colors, fonts, spacing variables, basic body text |
| `layout.css` | Header, nav, page grid, mobile → desktop breakpoints |
| `components.css` | Buttons, forms, tables, flashcard face |

## What should I change (or not)?

- Change **colors/fonts** in `base.css`.
- Change **page structure / breakpoints** in `layout.css`.
- Change **buttons, forms, tables, cards** in `components.css`.
- Do **not** put JavaScript or API URLs in CSS files.
