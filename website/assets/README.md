# website/assets/

## What is this folder?

Optional **images, icons, or other media** used by the website.

## What files matter?

Nothing required for v1. Add files here when you need a logo or illustration.

## What should I change (or not)?

- Put pictures here, then link them from HTML (for example `src="/assets/logo.png"`).
- Do **not** store flashcard JSON here — use `data/cards/` instead.
